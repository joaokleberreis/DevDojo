# Escopo da reconstrução

Este pacote contém 29 classes Java independentes, correspondentes às aulas 10–38.
Aulas com exercício foram reconstruídas com uma solução funcional para recuperar o material perdido.
Os exemplos foram escritos como material didático próprio, não copiados literalmente dos vídeos.

## Revisão importante antes de publicar
- Aula 11: tamanhos clássicos dos tipos primitivos; `boolean` não tem tamanho de armazenamento especificado pela linguagem Java.
- Aula 12: casting explícito pode truncar a parte decimal.
- Aula 24: exemplo didático de cálculo simplificado de imposto, não deve ser tratado como regra fiscal vigente.
- Os exemplos usam sintaxe compatível com versões modernas do Java e não dependem de recursos recentes.
- Nenhum exercício deve ser interpretado como prova de que o estudante o resolveu originalmente nesta reconstrução; os arquivos recompõem o material que foi perdido.
