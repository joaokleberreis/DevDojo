# Projeto 01 — Calculadora

## Objetivo
Calculadora de terminal desenvolvida com fundamentos de Java.

## Funcionalidades
- Soma, subtração, multiplicação e divisão.
- Proteção contra divisão por zero.
- Menu interativo e encerramento.
- Validação de entradas.

## Conceitos praticados
- Scanner, variáveis e operadores.
- Condicionais e switch.
- Laço do-while.

## Compilação
```bash
mkdir -p /tmp/devdojo-calculadora
javac -encoding UTF-8 -d /tmp/devdojo-calculadora Projetos/Calculadora/Calculadora.java
```

## Execução
```bash
java -cp /tmp/devdojo-calculadora Calculadora
```

## Testes
```bash
bash scripts/testar-projeto-calculadora.sh
```
