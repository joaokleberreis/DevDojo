# Projeto 02 — Menu Interativo

## Objetivo
Programa de terminal com um menu de utilidades desenvolvido em Java.

## Funcionalidades
- Calcular a média de três notas.
- Converter Celsius para Fahrenheit.
- Verificar se um número é par ou ímpar.
- Validar entradas e opções.
- Encerrar o programa pelo menu.

## Conceitos praticados
- Scanner e variáveis.
- Condicionais e switch.
- Laços while e for.
- Operadores aritméticos e validação.

## Compilação
```bash
mkdir -p /tmp/devdojo-menu
javac -encoding UTF-8 -d /tmp/devdojo-menu Projetos/MenuInterativo/MenuInterativo.java
```

## Execução
```bash
java -cp /tmp/devdojo-menu MenuInterativo
```

## Testes automatizados
```bash
bash scripts/testar-projeto-menu-interativo.sh
```
