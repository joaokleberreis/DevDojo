# Exercícios de Lógica

Oito exercícios de estruturas condicionais, operadores, laços de repetição e validação de entrada.

| Arquivo | Conteúdo |
|---|---|
| Exercicio01PositivoNegativoZero | Classificação de números |
| Exercicio02PodeVotar | Regras de idade para votação |
| Exercicio03MaiorDeTres | Maior entre três números |
| Exercicio04MenuOperacoes | Operações com switch |
| Exercicio05ContagemESoma | Contagem e soma de 1 até N |
| Exercicio06Fatorial | Cálculo de fatorial |
| Exercicio07Adivinhacao | Jogo de adivinhação |
| Exercicio08ValidarEntrada | Validação de intervalo |

## Compilação

```bash
mkdir -p /tmp/devdojo-logica
javac -encoding UTF-8 -d /tmp/devdojo-logica 06-Exercicios/Logica/*.java
```

## Testes automatizados

```bash
bash scripts/testar-exercicios-logica.sh
```
