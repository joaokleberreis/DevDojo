# Exercícios de Fundamentos

Sete exercícios complementares para praticar os conceitos iniciais de Java.

## Exercícios

| Arquivo | Conteúdo praticado |
|---|---|
| Exercicio01DadosPessoais.java | Variáveis e entrada de dados |
| Exercicio02ConversaoTemperatura.java | Operações matemáticas |
| Exercicio03MediaNotas.java | Cálculo de média e validação |
| Exercicio04Retangulo.java | Área e perímetro |
| Exercicio05Calculadora.java | Operações e condicionais |
| Exercicio06CalculoProduto.java | Cálculo de preço total de produtos |
| Exercicio07CalculoDesconto.java | Cálculo de desconto percentual |

## Compilação

A partir da raiz do repositório:

`javac -encoding UTF-8 -d /tmp/devdojo-fundamentos 06-Exercicios/Fundamentos/*.java`

## Execução

Após compilar, execute uma classe por vez:

`java -cp /tmp/devdojo-fundamentos Exercicio01DadosPessoais`

Substitua o nome da classe para executar os demais exercícios.

## Observação

Os exercícios foram implementados com validações básicas de entrada. São atividades de prática dos fundamentos da linguagem, sem uso de orientação a objetos além da estrutura necessária das classes Java.
